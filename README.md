Support Response Template AI Text Generator


Objectives


After completing this lab, you will be able to:


Create a REST API endpoint that accepts an issue type (e.g. "password reset")


Integrate with Gemini AI to generate contextual response templates


Have professional templates that support agents can use with customers


Build a UI interface to interact with your AI solution (optional)


Prerequisites


Knowledge of Java, Spring and REST APIs


A Google account for accessing the Gemini API
